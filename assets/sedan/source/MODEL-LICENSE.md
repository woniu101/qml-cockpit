# Tesla 2018 Model 3 model

- Creator: Ameer Studio (https://sketchfab.com/uchiha.321abc)
- Source: https://sketchfab.com/3d-models/tesla-2018-model-3-5ef9b845aaf44203b6d04e2c677e444f
- License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)

The model was obtained from FORMDRIVE's attributed copy and is rendered interactively in this Qt car-terminal demonstration.

Project modifications: Qt Balsam conversion; animation bindings for doors, glass and trunks; mirror triangles separated into pivot nodes; adjusted materials and texture orientation; selection highlighting and cameras. Original GLB retained unchanged. The charge-port flap, connector and cable are separate simplified geometry authored for this demo. See `THIRD_PARTY_NOTICES.md` for details.
