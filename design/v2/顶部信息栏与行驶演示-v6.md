# 顶部信息栏与行驶演示 v6

日期：2026-11-02。本轮对应用户提出的顶部排版不协调、D 挡演示不直观两项问题。

## 顶部信息栏

统一为 64 逻辑像素高度，时间、天气、地点、电量和连接图标按中心线 y=32 排列。时间采用固定宽度，天气图标、温度、地点分为独立元素；左右分组间距统一，电量和电池为一组。通知与头像使用 44×44 点击区域，角标固定在铃铛右上方。自动演示工具条缩窄，避让左侧驾驶状态入口和右侧电量。

首页新增“进入行驶演示”按钮，放在全局反馈区下方；顶部挡位/车速按钮仍可调整信号。全局反馈继续位于 y=83，不进入信息栏。

## D 挡可视化流程

- 首页“进入行驶演示”，或顶部驾驶面板“进入 D 挡行驶演示”，检查条件后切到独立行驶页，自动收起浮层。
- 初次开始为 D 挡 40 km/h；已在 D 挡行驶时进入页面保留当前车速。
- 无需导航路线即可自由行驶；不再只显示挡位与速度数字。
- 显示大号挡位/车速、本次累计行驶距离、SOC 和预计续航；累计距离在本次运行内保留，启动/恢复初始状态时清零，自动演示退出恢复原值。
- 车轮和道路标线由帧时钟按车速连续驱动，旋转原有轮胎、轮毂、轮心和制动盘网格；卡钳和转向连杆保持不动。轮周长使用演示近似值，非精确车辆动力学模型。
- 页面内可调速、选择 P/R/N/D、恢复 40 km/h、挂 P 驻车和快进 1 分钟。P/N 或车速 0 时停止道路与车轮；R 反向运动，限制 15 km/h。
- 路线独立：可在 P 挡规划；行驶页显示目的地、剩余时间/距离，并可切换地图。挂 P 保留导航；结束导航保留挡位。未规划路线时不会暗中创建默认目的地。
- 导航信息放在 3D 画面下方，避免遮住车轮；提供前视与跟车视角，也支持拖动旋转/缩放。
- 12 步自动演示中的行驶步骤切到此页面；暂停自动演示时，场景运动与模拟时间一同暂停。

## 验证

状态测试增加无导航行驶里程、倒挡限速、快进、驻车停止及快照恢复。界面回归覆盖：

1. 有开门状态时进入行驶被拦截，浮层保留受限反馈。
2. 符合条件后进入行驶页且浮层自动收起。
3. 无路线 D 挡行驶，实际 3D 区域画面发生变化，真实轮胎模型的旋转属性随车速更新。
4. 页面滑条调速，R 挡反向运动，P 挡后轮角与道路位置保持不变。
5. 自由行驶快进增加里程，规划路线后继续联动导航进度。
6. 顶部时钟和电量组的中心线一致；原车窗、充电、音乐、夜间主题、缩放、加载回退与演示恢复继续回归。

输出：`artifacts/v6/basic/`、`native/`、`dpi125/`、`release/` 和同级日志。实际截图 `22-driving-free.png`、`24-driving-parked.png`、`25-driving-route.png`、`26-status-home.png`；默认渲染测试另输出 `27-driving-final.png` 与 `performance.json`。

已通过状态测试、basic 界面回归、默认 D3D11 渲染回归及 125% DPI 回归；默认渲染还重复执行了 3 轮完整自动演示。实际触控验证沿用 Qt 合成双指事件，未连接实体触摸屏。

发布版 EXE 与开发版 SHA-256 一致；清除 Qt/QML 插件环境变量并把 PATH 限制为 Windows 系统目录后，发布版默认渲染界面测试通过，退出码 0。未在另一台电脑上测试。发布包附操作说明、此记录、实际画面和素材许可。

在本机 i7-12700KF / GT 730 上，标准画质行驶页连续运动的约 3 秒采样平均约 60 FPS，p95 帧时约 22 ms；这是短时测量，不代表所有电脑或长时间运行均稳定达到该帧率。100% 测试进程工作集约 511 MiB，峰值约 530 MiB，含已访问的多个页面。原始数据在 `artifacts/v6/native/performance.json`；125% 数据另存于 `dpi125/performance.json`。

功能仍是本地离线演示，道路为示意场景，不代表真实驾驶辅助、道路感知或车辆控制。
