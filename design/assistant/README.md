## 转入 QML 时

- 头像保留完整羊角轮廓，会话卡用 62 px，行驶卡用 43 px。设置页展示立绘。角色可隐藏，状态文案始终可读。
- 普通会话卡用一行结果。候选、追问或错误才扩展内容。停止播报与取消车辆动作使用不同入口。
- 用车机实际的确认、执行和播放状态驱动界面。候选顺序同时供触屏与后续语音序号选择使用。
- 音色设置保留已保存的参考音频和原文。「恢复默认播放设置」只恢复语速、播报音量和回复方式。
- 首页与行驶底图引用仓库已有车机截图，角色使用用户提供的原图。画板只评审助手区域，正式界面使用现有 QML 车型与页面组件。
