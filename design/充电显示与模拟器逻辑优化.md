# 充电显示与模拟器逻辑优化

日期：2026-11-02。根据充电枪造型、按钮文字裁切和充电按钮使能的反馈，已完成本轮开发优化。

## 充电显示

- 充电枪改为金属接口、接口密封圈、浅色外壳、锁扣、握柄、握柄防滑圈和线缆接头，替换原来的直圆柱造型。
- 橡胶线缆使用连续圆管曲面，从枪柄自然下垂并沿地面弯曲延伸，不再是悬空的直线。该造型为演示几何，不是精确车型配件。
- 充电时枪体状态灯缓慢呼吸；暂停或数据不可用时停止动态效果。拔枪后枪体和线缆隐藏。
- 补能页增加状态指示点、电量条流动高光和目标位置刻度；显示正在充电、已连接、达到目标和数据过期等状态。达标后开始按钮禁用，目标提高后可继续。

## 模拟器布局

- 按钮有最小高度，布局按内容计算尺寸，开始/暂停充电使用整行的两列按钮；不再挤进窄表格单元格。
- 宽窗口双列；小于 1000 个逻辑像素时切为单列。内容超出可视区域时滚动访问，避免通过压缩按钮来塞入窗口。
- 提示文字自动换行，延迟数值与说明分开。100% / 125% 缩放均检查按钮文字所需尺寸；820 × 620 小窗口检查无横向裁切。

## 按钮和互锁

| 状态 | 开始充电 | 暂停充电 | 插枪 / 拔枪 | 充电口 / 换挡 |
|---|---|---|---|---|
| 未插枪 | 禁用 | 禁用 | P 挡且开口时允许连接 | P 挡允许操作充电口 |
| 已插枪且未达目标 | 启用 | 禁用 | 允许断开 | 禁止关闭充电口和切入 N/D/R |
| 正在充电 | 禁用 | 启用 | 禁止拔枪 | 禁止关闭充电口和切入 N/D/R |
| 已达到目标 | 禁用 | 禁用 | 允许断开 | 提高目标后可重新开始 |

- 控制台按钮使能与服务端执行共用 `commandError()` 校验，灰色操作提供原因；服务端继续兜底校验来自车机的请求。
- P/N 不能修改非零速度；R 限速 15，D 限速 100；电量为零时禁用车速输入。车门及备厢未关闭或开合未结束，不能启动行驶。
- 车门开合、备厢开合期间对应控件暂时禁用；增加全部关门、门锁、前后备厢与后视镜折叠控件。
- 无行驶、无充电时禁用快进；已驻车时禁用重复驻车；没有车机连接时禁用断开连接。
- 新增故障摘要与“清除全部故障”，将车辆重置和故障清除分别呈现，避免重置车辆后误以为故障也已恢复。

## 修复的后端问题

1. **插枪/充电时还能切 N 挡**：车机内置模型和独立模型均禁止，避免出现 N 挡仍在充电的组合。
2. **重置后旧延迟请求再次执行**：延迟请求显式管理，重置、断开和停止服务均会撤销；新目标或停止操作可以替换同部件尚未执行的旧请求。
3. **暂停后旧的延迟充电开始又触发**：同一充电开关的排队操作可以被后续停止操作撤销。
4. **低电量快进累计超过可行驶里程**：独立模型按剩余电量限制本次距离，到零后停止。
5. **同状态设置被误判为非法操作**：重复保持已插枪、已开口不再产生副作用或被错误拒绝。
6. **输入焦点和远端数据互相覆盖**：只有用户修改过的数值提交；未修改的输入框即便有焦点也持续显示模型数据。真实编辑期间保留输入，拒绝后恢复确认值。

清除延迟故障只恢复后续请求；已经排队的请求按原计划处理，可以用新操作或重置取消。停止“服务”只断开通信，虚拟车辆模型仍可在控制台调试，状态栏明确说明。

## 验证

- 两仓库构建通过，状态与协议测试通过，新增了插枪换 N 挡、目标变更、同状态操作、低电量里程，以及延迟请求被重置/停止撤销的测试。
- 模拟器真实鼠标/键盘测试覆盖开始/暂停/达标、拔枪/开口使能、N/D 选项禁用、前备厢与后视镜、故障清除、服务重启及小窗口布局；100% 和 125% 通过。
- 两进程联调在 100% / 125% 通过，原有默认渲染回归通过，覆盖车辆、导航、音乐和充电。该轮未重跑长时间浸泡测试。

## 后续仍可完善

1. **场景脚本与重放**：一键执行上车出发、低电量补能、断线恢复等场景，支持保存场景、录制与回放，便于稳定复现。
2. **按部件注入故障**：增加单窗卡滞、单门故障、充电故障和传感器异常，替代目前主要针对整条链路的拒绝/延迟。
3. **时间控制**：独立的暂停演算、单步和倍率；与“暂停遥测”区分，暂停遥测目前仍让车辆模型继续运行。
4. **能量模型**：目前仍是固定 55 kW 和固定能耗，可逐步加入高 SOC 降功率、负载和环境影响。
5. **持久化记录**：日志导出、请求按 ID 查询和配置预设；运行状态及故障不应无提示地在下一次启动恢复。

本轮保留开发版工作流，不生成便携包。
