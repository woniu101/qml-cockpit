# 首页充电信息布局调整

日期：2026-11-02。按确认的方案，将首页两块充电展示合并到左上电量区。

## 当前布局

- 删除原来的白色充电长条，首页车模不再显示浮动充电卡。
- 在电量/续航下方、与左侧文字对齐的位置显示一行透明摘要：状态、实际功率、到目标的预计时间，以及“查看补能”入口。
- 状态用对应强调色，功率用正文色，时间等信息用次级色。日期行只显示日期，避免重复表达正在充电。
- 保留车模上的流动光点、车底呼吸光晕和分段电量示意；SOC 分区和充电执行逻辑不变。
- 首页摘要不重复显示一份 SOC。完整电量与控制位于“车辆 → 充电与补能”。2026-11-03 全局优化后，其他车身页同样移除浮动电量卡。

## 状态与入口

| 状态 | 摘要 |
|---|---|
| 充电中 | 正在充电、实际 kW、约多少分钟至目标百分比 |
| 已连接未充电 | 已连接 · 未充电，提示可在补能页开始或继续 |
| 达到目标 | 已达到目标 90% 等，提示补能已停止 |
| 100% 满电 | 电池已充满，提示可断开充电枪 |
| 数据失效 | 车辆数据已过期，等待连接恢复；不显示旧功率为当前功率 |
| 只打开充电口 | 提示连接充电枪后开始补能 |

“查看补能”直接定位到车辆页的充电控制，不需要再次选择分类。数据失效时仍可进入详情查看，远端控制保持禁用。

原长条包含的门窗/备厢状态没有丢弃：存在充电信息时，用同一行中的“几项提醒”入口打开当前提醒；没有充电信息时，该行可显示车身状态和“查看提醒”。普通锁车/后视镜信息仍可从顶栏提醒入口查看。
