# 助手界面与语音流程改造方案

本方案依据界面、代码和用户截图制定。2026-11-05 已完成本轮界面与流程重构；下文保留设计目标，文末记录实际验收范围。三首默认演示音乐已从默认媒体库移除，测试音源在测试中临时生成。

## 会话卡

- 入口和会话卡继续位于底栏右侧。听取、识别、理解、等待确认、执行、播报和失败各有明确文案。
- 确认类操作使用同一行的「取消」「确认执行」，高度一致，确认具有主要操作样式。动作计划按项列出。
- 多候选使用等宽位置网格或编号列表，操作底部放独立取消栏。保留「选第二个」「取消」语音路径。
- 执行过程中显示实际进度。取消后续的按钮和关闭会话的按钮分开，已提交的动作继续等待真实结果。
- 增加重播回复、收音状态和播报失败提示。长结果可展开，录音按钮与关闭按钮保持固定位置。

## 播报规则

改造前，文字发送未标为语音请求，因此不会触发 ZipVoice。「语音＋文字」标签未表达这项限制。

改为明确的三种偏好「语音＋文字」「仅语音输入时播报」「仅文字」。第一种对文字、触屏选择和语音请求的最终回复均播报。确认追问允许播报，执行过程的频繁遥测只更新画面。缺少输出设备、模型未就绪或合成失败时显示对应原因并提供重试。

## 设置布局与控件

- 顶部统一为返回按钮、座舱助手标题和关闭按钮，左侧仅保留分类导航，右侧显示当前分类。
- 分类为声音、形象、唤醒与对话、开发调试。开发调试入口弱化。
- 统一使用项目的 SoftComboBox、开关、输入框、按钮和状态提示。设备列表支持长名称省略与查看完整名称。
- 内容按卡片分组，统一边距、标题层级与控件高度，避免大量留白。滚动限于内容区，底部主要操作固定可见。
- 按日间、夜间、1120×630 最小窗口和 125% 缩放验收。

## 音色创建与管理

入口分为「导入音频」和「朗读录制」，共用同一个创建流程。

1. 获取参考音频。导入支持 WAV 与 MP3，麦克风录制提供倒计时、输入电平、停止和重录。
2. 校验并显示参考片段。先解码，再检查实际时长、静音、声道和有效语音，统一为供模型使用的 PCM。超长片段要求选择范围。
3. 核对参考原文。导入音频可先识别原文供确认。朗读录制提供约 8–12 秒的提示文本，录制后核对是否读漏。参考原文与试听文案分别保存。
4. 生成试听。提供默认句子和自定义试听文案，可先听原声再听生成效果，支持停止、重试和重新录制。
5. 保存并启用。区分正在编辑的音色与当前启用音色，离开未保存时提供保留或放弃的明确操作。

音频解码与校验封装为共享模块，指令回放和参考音色分别应用时长限制。MP3 支持需用真实文件验收，损坏和不支持的文件给出实际失败原因。

## 无键盘操作

- 日常命令、补充窗位、确认、取消、候选选择和结束会话均提供语音路径。
- 音色录入可直接朗读给定文本，原文确认、重录、试听和启用都有大按钮。
- 自定义试听可用麦克风口述。识别后展示文本，确认再生成。
- 选择文件、图片和复杂调试参数继续提供触屏操作。后续虚拟键盘复用统一文本输入入口。
- 录音期间暂停助手播报，播报中的唤醒打断与连续对话按实际音频状态协调。扬声器回声与远场效果单独做硬件验收。

## 形象编辑

- 左侧为主要裁切画布，右侧为实际使用效果。导入后可以拖动图片、滚轮缩放，触屏支持平移和双指缩放。
- 缩放以当前可见构图为中心，限制图片边界，保留居中、重置和精细滑块。
- 预览按「底栏入口」「会话头像」「设置预览」分别显示，注明使用位置，头像中心与标签对齐。
- 提供待机、聆听、处理、播报、成功与失败的状态预览。默认素材的表情动效与自定义图片的通用动效分别说明。
- 导入、裁切草稿、保存启用和取消恢复使用同一份状态，减少频繁生成临时图片。

## 开发调试

- 测试输入区提供文字、录音文件、回放及记录开关。
- 结果区以输入原文、ASR 转写、当前模型、对照模型、准入结果、执行回执分别展示，JSON 可折叠和复制。
- 人工纠错单独为表单，中文标签与模型字段对应。行为类别、意图和参数有明确关联，非法 JSON 就地提示。
- 录音识别错误、语义理解错误、命令不支持、设备不可用和车辆执行失败使用不同结果。

## 自然表达与失败回复

改造前，「主驾温度调高点」未匹配相对调整解析。此前主要支持「再高一点」等依赖上下文的句式。

- 支持明确对象的相对调整，例如主驾温度调高点、副驾降两度、左前窗再关一点。明确目标以当前实际状态计算，不能沿用不相符的旧目标。
- 「有点热」等缺少明确对象与动作的表达先追问。
- 不理解时说明具体问题，例如「没理解这次要调整什么，可以再说一次」。
- 识别出空调、车窗或媒体主题时，给相应的一条引导。缺参数、越界、缺文件、蓝牙来源受限、失联与不支持动作分别解释。
- 能力帮助通过主动询问或单独入口打开。

## 实施与验收顺序

实现时集中管理会话状态与播报策略，分别记录输入来源和是否需要播报。音频导入共用解码与校验逻辑，音色创建持有独立草稿，动作执行继续使用既有车辆接口，页面只绑定状态并发起操作。统一控件复用并完善现有 SoftComboBox 等组件。

第一轮完成会话卡、设置骨架、统一控件、播报策略、相对调整与失败文案。验收文字与语音回复一致，确认操作完整可见，窗口缩放和滚动不影响背景。

第二轮完成共享音频导入、MP3、音色向导与提示朗读录制。验收无键盘创建音色、原文与试听文案独立、错误可恢复。

第三轮完成鼠标与触屏裁切、实际尺寸预览、状态动效与调试工作台。验收修改草稿、取消、保存和重启后的结果一致。

每轮先交付可审阅的界面与流程，再接通运行状态并验收。模型训练继续独立处理。

## 本轮交付与验收记录

- 已拆分设置分类、统一卡片/输入框/开关/下拉框；确认和取消位于同一行，候选列表保留独立取消入口。开发调试分为测试输入、结果和纠错表单，并区分未调用模型与等待模型结果。
- 最终回复统一携带输入来源交给播报模块，按三种偏好处理；保留显式重播、取消合成和停止播放。文字请求在实机触发 ZipVoice 合成。
- `AssistantAudioClip` 共用 WAV/MP3 解码、PCM 规范化、片段选择、静音幅度检查和录制。音色源文件上限 120 秒/32 MB，参考片段 1–15 秒；指令文件 0.2–10 秒。静音检查依据幅度，未加入说话人数或噪声分类模型。
- 音色向导区分启用音色、编辑草稿、参考原文和试听文案。导入后转写、口述填写、倒计时提示朗读、试听后保存已接通；表单口述不会进入车控。草稿在当前进程内保留，启用音色和头像持久保存。
- 头像编辑支持拖动、滚轮、双指缩放及实时多尺寸预览，取消恢复原形象。实机已验证鼠标缩放、拖动和取消；触屏手势仍需真实触屏验收。
- 支持带明确对象的相对温度/车窗调整，不再覆盖成上次对象；不理解时按主题提示，感到冷热时先询问调整方向，不自动改车控。
- 全部 7 个 CTest 测试集通过；真实短 MP3 解码/裁切/取消、口述与命令信号隔离、ZipVoice 音色保存及播报策略、相对目标测试通过。14 个 QML 组件离屏实例化无 QML 警告。
- 实际 Windows 窗口检查涵盖会话、声音页、音色向导、形象页、调试页、统一下拉框，以及 1120×630 客户区下的会话和设置显示、125% 缩放下的夜间声音页和长文本内部滚动。麦克风当前不可用，真人朗读、远场唤醒、扬声器回声和实际听感不计为已验收。

虚拟键盘、任意聊天能力、语音识别/NLU 模型训练不包含在本轮，后续分别推进。
